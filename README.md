# MAJORLEAGUE — THE VAULT

GitHub Pages-ready static storefront using the Majorleague logo and category artwork already in this repository.

## Easy stock updates
Edit **stock.js** only: name, price, image, availability and category. Put product images in assets/products/ and set the image path.

## Homepage video
Later add **assets/hero.mp4**. No other code changes are required.

## GitHub Pages
Repository: MLB1111/Majorleague-vault. Enable Pages from Settings → Pages → Deploy from branch → main → /(root).

The checkout UI is a front-end template for lawful products and should be connected to an appropriate fulfilment/order system before real transactions.
