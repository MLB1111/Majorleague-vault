# Majorleague Vault — Category artwork

Upload the **approved, final banner images** into this folder. Keep the artwork unchanged.

## Required filenames

Use these exact filenames so the site can reference each banner consistently:

- `flower-category.webp`
- `extracts-category.webp`
- `edibles-category.webp`
- `accessories-category.webp`
- `special-offers-category.webp`

## Upload from iPhone

1. Open this folder in GitHub: https://github.com/MLB1111/Majorleague-vault/tree/main/assets/categories
2. Tap **Add file** → **Upload files**.
3. Select the final artwork images from Photos/Files.
4. Rename each file to the exact filename above before uploading (or rename it in Files first).
5. Tap **Commit changes**.

If your artwork is JPEG or PNG rather than WebP, either keep the original extension and tell us the filenames, or convert it to WebP before upload. Do not simply rename a file extension without converting the image.

## Artwork requirements

- Use the final approved designs, not screenshots or previews.
- Preserve the artwork exactly; do not crop, recolour, or recompress it unnecessarily.
- Keep each banner's yellow border and all artwork inside the border.
- The website has not been changed by this setup step. The images will be connected to the site after all five are uploaded and verified.
